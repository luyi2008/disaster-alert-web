# 登录模块：手机验证码输入框

日期：2026-09-07（更正）

先前把「验证码」听成了「二维码」。**真正要加/重做的是手机登录段的短信验证码输入。** 扫码界面已经画过，本轮先保留，不删、不作为本页主角。

可交互稿仍是 `docs/design/login-qr-field.html`（打开后默认停在手机号段）。扫码段点「扫码」或「微信」仍可看。

Figma：[灾害预警 · 登录二维码输入框](https://www.figma.com/design/Y1k112CejokbNLMf8Hl9co)（扫码稿，先留着）

## 1. 对象与一句话

- **产品**：灾害预警值班台。
- **谁来用**：用大陆手机号进值班台、再绑 Bark 设备的人。
- **这一屏的工作**：输入手机号，填 6 位短信码，登录。验证码是这张表单里最需要对准的一格，不是普通单行文本。

现网 `/login` 已有「验证码」+「发送验证码」，但是一条 36px 输入加描边按钮，和手机号抢视觉，也不像 6 位码。本设计替换这个控件的样子，不改 BFF 契约（仍是 6 位数字，mock 固定 `000000`）。

## 2. 方案比较

| | A. 六格读数井 + 标签行发送（推荐） | B. 保持单行输入，只改间距/文案 | C. 六个独立圆角盒 |
| --- | --- | --- | --- |
| 做法 | 一个字段井，竖线分成 6 格。发送是标签右侧的文字按钮。 | 现网结构不动。 | 六只分开的小输入框。 |
| 好处 | 格子数等于码长；粘贴/短信自动填充仍走一个隐藏 input。 | 改动为零。 | 常见、好认。 |
| 代价 | 要改 `OtpInput`。 | 看不出「增加了验证码输入框」。 | 像通用验证码模板，和值班台仪器感无关。 |

**采用 A。** 扫码准星井先留在「扫码」段，本轮不改。

## 3. 视觉计划

沿用现网 zinc token 与系统黑体。不另起登录皮肤。

### 色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| Paper | `--background` | 表单、井底 |
| Ink | `--foreground` | 数字、发送 |
| Stroke | `--input` / `--border` | 井边、格线 |
| Quiet | `--muted-foreground` | 等待短线、倒计时 |
| Fault | `--destructive` | 空码、错码 |

### 字

- 展示：现网标题 28px / 600。
- 标签：13px / 600，与 `Field` 一致。
- 码：`--font-mono`，20px，等宽数字，像台站读数，不用展示衬线。

### 布局

```
[ 品牌 灾害预警          主题 ]
及时知情，及时避险
用手机号或微信登录后，再绑定设备的推送令牌。

┌ 卡片 ─────────────────────────┐
│ [ 手机号 | 扫码 ]               │  ← 扫码段保留
│                                │
│ 手机号                         │
│ [+86][ 11 位大陆手机号     ]   │
│                                │
│ 验证码              发送验证码  │
│ ┌──┬──┬──┬──┬──┬──┐          │
│ │  │  │  │  │  │  │          │
│ └──┴──┴──┴──┴──┴──┘          │
│                                │
│ [           登录           ]   │
└────────────────────────────────┘
或者
[ 微信 ] [ 支付宝 ] [ Google ]
```

发送不再和输入抢同一行宽度。六格需要完整一行。

### 签名元素

**六格读数井。** 一只字段，六格用发丝竖线切开，不是六只小卡片。空格中央一条短横（仪器在等信号），当前格底边加粗。聚焦环与手机号输入相同。这是本页唯一放大的东西；扫码井先原样放在另一段。

不采用：六个圆角盒、微信绿、大号倒计时环。

## 4. 字段行为

| 零件 | 行为 |
| --- | --- |
| 标签 | 验证码 |
| 发送 | 标签行右侧。未发：发送验证码。发送中：发送中。冷却：56s。无效手机号不发，错误写在手机号槽。 |
| 井 | 一个隐藏 `input`：`inputMode=numeric`，`autoComplete=one-time-code`，最多 6 位数字。点击任一格即聚焦。支持整段粘贴。 |
| 空格 | 中央短横，不写 0、不写 ○。 |
| 当前格 | 底边 2px Ink。 |
| 登录 | 现网主按钮。码空则「请输入验证码」。 |

### 状态

| 状态 | 井 | 提示槽 |
| --- | --- | --- |
| 默认 | 六格皆空，短横 | 预留高度，空 |
| 输入中 | 已填数字 + 当前格底边 | 空 |
| 满 6 位 | 六格都有数字 | 空 |
| 校验失败 | 井边 Fault | 验证码错误，请重新输入 |
| 未填提交 | 井边 Fault | 请输入验证码 |

`prefers-reduced-motion: reduce` 时不闪烁光标，只保留底边。

## 5. 扫码（先保留）

「扫码」段、微信入口切到扫码、准星井、mock 票据读数带，维持上一版，不在本轮重画。手机号段是默认打开的面。

| 位置 | 文案 |
| --- | --- |
| 分段 | 手机号 / 扫码 |
| 标签 | 验证码 |
| 发送 | 发送验证码 / 发送中 / Ns |

| 校验失败 | 验证码错误，请重新输入 |
| 手机号非法 | 请输入 11 位大陆手机号（现网，写在手机号槽） |
