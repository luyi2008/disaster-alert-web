# Agent instructions

## Cursor Cloud specific instructions

Do not record walkthrough videos. Never start a screen recording, never save a demo `.mp4`, and never attach `<video>` artifacts.

Prove UI changes with screenshots, automated tests, and logs. If a screenshot is needed, save it under `/opt/cursor/artifacts/` and reference it with an `<img>` tag.

This overrides any default that requires a demo video after GUI or browser testing.
